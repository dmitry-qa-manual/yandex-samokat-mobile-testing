# Yandex Samokat — Mobile Testing

## 📋 Project Overview

This project was completed as part of the Yandex Practicum Software Testing diploma project.

The goal was to test the Android version of the Yandex Samokat application and verify its functionality under different application and device conditions.

## 📱 Testing Activities

- Functional testing
- Regression testing
- Mobile application testing
- Push notification testing
- Positive and negative testing
- Testing different application states
- Testing notification permissions
- Network error testing
- UI testing
- Bug reporting

## 🔔 Push Notifications

The following scenarios were tested:

- Receiving push notifications at different times
- Receiving notifications with the application open
- Receiving notifications with the application minimized
- Receiving notifications with the application closed
- Receiving notifications on the device lock screen
- Behavior when notifications are disabled
- Notification title and text
- Order address and order number in notifications
- Opening the application from a push notification

## 🌐 Network Error Handling

The application was tested with no internet connection.

The following behavior was verified:

- Error window appearance
- Error window title and text
- `OK` button availability
- Closing the error window
- Repeated appearance of the error window
- Correct display of UI elements

## 🧪 Test Environment

- Android Studio
- Google Pixel 7
- Android 13.0 Tiramisu
- Resolution: 1080×1920
- Yandex Samokat 2.0

## 🐞 Defects Found

During testing, several defects were identified and documented, including:

- Push notification not displayed at the expected time
- Push notifications not displayed in different application states
- Application crash when opening the application from a push notification
- Push notification not displayed on the device lock screen
